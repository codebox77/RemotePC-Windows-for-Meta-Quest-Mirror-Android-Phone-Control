# RemotePC for Meta Quest

Windows PC 화면을 Meta Quest로 스트리밍하고 원격으로 조작할 수 있는 RemotePC 앱입니다.

![RemotePC 실행 화면](./ScreenShots.gif)

## 다운로드 및 설치

### Windows PC

[최신 버전 RemotePC.exe 다운로드](https://github.com/codebox77/RemotePC-Windows-for-Meta-Quest-Mirror-Android-Phone-Control/releases/latest/download/RemotePC.exe)

`RemotePC.exe`를 내려받아 Windows PC에서 실행하세요.

### Meta Quest

[Meta Quest Store에서 RemotePC 설치](https://www.meta.com/experiences/quest/886009210932925/)

위 링크를 열어 Meta Quest에 앱을 설치할 수 있습니다.

## 사용 방법

1. Windows PC와 Meta Quest를 신뢰할 수 있는 동일한 사설 네트워크에 연결합니다.
2. PC에서 `RemotePC.exe`를 실행합니다.
3. 캡처할 모니터, 전송 FPS, 화질, 해상도 등의 설정을 선택합니다.
4. Windows 방화벽 메시지가 나타나면 **개인 네트워크**에서만 통신을 허용합니다.
5. PC 앱에서 서버를 시작합니다.
6. Meta Quest에서 RemotePC 앱을 실행하고 PC에 연결합니다.
7. 첫 연결 승인 옵션을 사용 중이라면 PC에서 연결 요청을 승인합니다.

## 보안 주의사항

RemotePC의 화면 및 제어 트래픽은 암호화되거나 인증되지 않습니다.

- 가정이나 사무실의 신뢰할 수 있는 사설 네트워크에서만 사용하세요.
- 공용 Wi-Fi에서는 사용하지 마세요.
- 공유기의 포트 포워딩을 설정하거나 RemotePC 포트를 인터넷에 공개하지 마세요.
- Windows 방화벽에서는 공용 네트워크가 아닌 개인 네트워크에만 접근을 허용하세요.
